## RequestFrame.context_needs

该字段表示本轮请求加载哪些上下文，可以同时包含多种类型。上下文准备流程仍会按安全规则补充安全约束，不能将空元组理解为跳过过敏检查。

| 取值 | 业务含义 |
| --- | --- |
| `recent_conversation` | 近期对话消息，用于承接上一轮、消解指代或修改已有任务。 |
| `allergies` | 用户过敏记忆，用于过滤可能引发过敏的食材。 |
| `dietary_restrictions` | 用户饮食禁忌与限制记忆。 |
| `food_preferences` | 口味、喜好、厌恶及相关健康目标或烹饪时间记忆。 |
| `episodic_memory` | 历史任务或菜单的片段记忆，用于恢复此前任务情境。 |
| `user_profile` | 用户画像和个人事实的上下文需求标识，区别于登录身份；实际加载能力由上下文提供器决定。 |

RequestFrame 的其他字段，包括任务、记忆变更、本轮约束、偏好、目标、分类配额、人数、理解状态和降级信息，均已在定义旁说明。
