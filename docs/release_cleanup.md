## 中文说明覆盖

检查范围为整个 `safemeal/**/*.py`，包括 Agent、业务模块、基础设施、配置、装配、
HTTP 接口以及 SQL 迁移。实际覆盖 **315 个类、975 个函数／方法**；**20 个 SQL 类**
均有明确标识。接口、异常、枚举和数据契约类也分别标明用途。

每个方法的块注释包含：

1. 实际业务作用；
2. 每个显式参数的名称、类型、含义和默认行为；
3. 返回类型与含义，无返回值时标明 `None`。

`self`、`cls` 是隐式绑定参数，不作为调用方输入重复列出。注释位于定义和装饰器之前，
不替换工具用途字段、Pydantic 字段描述或模型提示内容。另纠正了会话和消息 ORM 中
两处过时的文档字符串。

新增 `scripts/check_backend_comments.py`，通过 AST 检查逐符号说明、参数遗漏和 SQL 标识。
运行 `make comments-check`；该检查也已加入 `make check`。
